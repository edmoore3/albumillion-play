# Albumillion

A daily music game. Seven questions, the same seven for everyone, and the
answer nobody else thinks of is worth the most. Play it at
https://edmoore3.github.io/albumillion-play/.

This repository holds only the built site: one page and its questions,
258 of them, built 2026-09-15. It is generated from the private
Albumillion repository by `python -m albumillion.export_static`; changes
made here are overwritten by the next build.

Answers come from MusicBrainz (CC0) and Wikipedia's "List of music genres and
styles" (CC BY-SA 4.0, https://en.wikipedia.org/wiki/List_of_music_genres_and_styles).
Rarity comes from Last.fm listening, MusicBrainz release counts and Wikipedia
pageviews; no raw figures are published. Label art is loaded from the Cover
Art Archive. Albumillion is not affiliated with any of these services.
